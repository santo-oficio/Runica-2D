Calibrar area de instrucciones
Marca la zona donde ira el texto (se ve con el contenido real)

B = editar BOTON ATRAS (redondo: arrastra desde el centro)
Arrastrar = marcar area
Espacio = clonar (mismo tamano)
Flechas = mover seleccion (Shift = fino, Ctrl = ultra)
+ / - = agrandar / reducir
Q / E = ancho (Shift = fino, Ctrl = ultra)
0-9 = seleccionar area
Z = deshacer ultimo
T = mostrar/ocultar texto
G = guardar JSON
C = cargar guardado
